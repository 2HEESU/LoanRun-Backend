# 전체 계획 조회 (#23)

GET `/api/plans/overall/`는 PRO 전용이며 FREE는 403이다. 활성 0~1개 SINGLE_LOAN, 다중이지만 전략 최초 반영 전이면 EMPTY, 실제 적용 이벤트가 있으면 AVAILABLE이다. 최초/최근 적용 시각·전략·우선순위는 저장 원천으로 확인하고 revision 변화는 needs_review에 반영한다. 단순 다중 대출 등록/직접 입력만으로 전체 전략이 존재한다고 가정하지 않는다.

기존 개별 계획의 현재 추정/가계 집계를 재사용하며 실제 전체 적용 이벤트와 장기 배분을 별도로 조합한다. 당월 override로 장기 목표를 덮지 않는다. 적립 목표는 monthly_saving_amount로 별도 표시하고, 전체/개별 금액은 세션 소유자에 한정한다. 원천 부족은 null/503이며 GET은 원본/버전/revision을 변경하지 않는다.

필수 예산/V4 버전/전체 적용 이벤트 저장소는 기존 합의된 공통 DB 적용 이후 필요하다. Flyway/환경변수/의존성 변경 없음. 공통 포트를 조기 설치하지 않고 내부 저장 조회를 이용하여 기존 V2 적립 경로를 보존한다.
