# 실제 납부 삭제 (#30)

DELETE `/api/payments/{payment_id}/`는 본문을 받지 않는다. Idempotency-Key는 명세대로 필수로 추가하지 않으며, 제공하면 같은 요청을 삭제 이후에도 재사용한다. 키 없는 반복 삭제는404다. 타인/없는 납부404 PAYMENT_NOT_FOUND, 최신 보정에 포함된 기록/후속 원장 충돌은409 PAYMENT_DELETE_CONFLICT다.

사용자/대출 잠금 아래 원본을 제거하고 남은 실제 구성을 날짜/ID 순 재처리한다. 정기 배분·현재 원금·적립 사용·대출 상태·미확정 미래 회차·예산 정산·revision을 한 트랜잭션으로 갱신한다. 다른 실제 기록의 금액/구성/작성 시각과 과거 약정은 바꾸지 않는다. 적립 사용 취소는 해당 대출 자산으로 돌아오며 예산 현금에 중복 가산하지 않는다.

완납 취소는 활성 7개 제한을 확인하고 보존된 실제 회차 ID/필요액/이자를 복원한다. 날짜가 지난 회차도 보존 원천으로 복원하며 현재 잔액으로 과거 의무를 추측하지 않는다. 미납 의무 또는 실제 배분이 있는 부분 회차를 남긴 채 완납으로 표시하지 않는다. 반환 schedule_status는 실제 보존 회차의 상태다. 예산/응답 계산 실패는 삭제/배분/회차 보존·복원/잔액/revision/멱등 응답을 모두 롤백한다.

기존 회차 보존 SQL과 실제 예산 공급이 필요하며 없으면503이다. Flyway/환경변수/의존성 변경 없음.
