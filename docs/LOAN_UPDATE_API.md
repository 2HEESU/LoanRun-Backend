# 대출 정보 수정 (#16)

`PATCH /api/loans/{loan_id}/`는 상세 명세에 허용된 필드만 받는다. 생략은 유지, 명시 null은 nullable 필드에만 허용한다. 금리 수치는 #19로만 변경하며 상환 방식·상품 ID·소유자 주입을 거절한다. 직접 입력 상품명/기관명은 수정 가능하고 공시 상품명 변경은 400이다. 200 `LOAN_UPDATE_SUCCESS`의 data는 공통 대출 객체다.

실제 잔액 변경 시 오늘의 `CORRECTION` 스냅샷을 추가하고 현재 잔액/앵커/미도래 미확정 회차를 재계산한다. 등록 스냅샷·금리 이력·납부 원본·기존 계획 기준은 보존한다. 잔액 0이고 보존할 미납 의무가 없을 때 PAID로 전환하고 미확정 미래 회차를 제거한다. 약정 다음 납부액은 해당 회차 한정이며 완료된 회차의 입력액을 다음 회차에 복제하지 않는다.

사용자/대출 잠금 및 단일 트랜잭션으로 스냅샷·약정·회차·예산 재계산·revision을 처리한다. 재계산 공급이 없거나 실패하면 503 및 전체 롤백이다. 동일 값/빈 PATCH는 원본·revision·예산을 변경하지 않는다. 이름만 바꾸면 revision은 갱신하되 금융 예산 재계산은 하지 않는다.

과거 잔액보다 작은 최초 원금, 원본 기록과 충돌하는 실행/만기일, 부분/미충족 과거 회차, 확정/배분된 대상 회차, 복수 미확정 미래 회차 등 안전한 재계산 기준이 없는 정정은 409 `LOAN_UPDATE_CONFLICT`다. 현재 회차 계산 원천이 없는 완납 대출의 금융 정보 정정/재활성화는 같은 충돌로 거절하며 이름/동일 값 정정은 가능하다. 미래 확정 회차를 옮기거나 과거 의무를 지우지 않는다. 새로운 런타임 마이그레이션·환경변수·의존성 없음.
