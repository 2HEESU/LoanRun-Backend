## 보존 및 검증

- 계획은 미리보기 token/revision 재검증 후 새 버전을 append한다. 원래 계획·당월 override·실제 납부를 덮지 않는다.
- 납부는 실제 날짜/ID 순 재처리하며 실제 구성, 최신 잔액 보정, 확정 회차를 보존한다. 원금/이자/비용/정기/추가/적립을 분리한다. 실제 0원과 미기록을 구분한다.
- 완납 취소에 필요한 미확정 회차는 삭제 전 보존하고 같은 실제 ID/원래 필요액/이자로 복원한다. 현재 잔액으로 과거 의무를 만들지 않는다. 부분 의무를 남긴 채 완납으로 표시하지 않는다.
- 사용자/대출 잠금 아래 원본·파생 배분/잔액·미래 회차·예산·revision·멱등 응답을 한 트랜잭션으로 처리한다. 실패는 전체 롤백, 같은 값 수정은 금융 재계산/revision 변화 없음이다.
- Java 21 clean build: **826개 테스트, 실패/오류/건너뜀 0**. 정상/입력/소유권/PRO/stale/멱등/날짜·원금·수수료·자산 경계/완납 취소/원약정 복원/실패 롤백을 포함한다. 최종 CI·머지 상태는 PR 기록에서 확인한다.
