## 운영 연결과 데이터 검증은 별도

- 실제 예산 조회/재계산, 전체 전략 상태/후보, 과거 목표/월초 잔액 등 공통 포트 공급이 아직 없다. 필요한 원천이 없으면 503 또는 명세가 허용하는 null을 유지한다. 테스트 대역은 테스트에서만 사용한다.
- observed는 실제 기록 완료 또는 실제 0 확인에만 true다. 납부와 BULLET 적립의 명시 확인 원천이 아직 없어 런타임의 미확인 실적 합계/비율은 null이다. 건수나 회차 PAID로 완료를 추측하지 않는다.
- V4 불변 계획 버전 SQL은 계속 제안/격리 테스트용이며 Flyway에 활성화하지 않았다. V3/V5 실제 개발 DB 적용 상태 확인 및 공동 적용 순서 확정이 필요하다. 적용 이력을 재작성하거나 checksum을 덮지 않았다.
- 확정/부분/미충족 과거 회차 또는 안전한 현재 계산 기준이 없는 정정은 409/503이다. 명시적으로 뒤 회차에 적용하려는 미리보기는 미래 잔액 원천이 필요하다.
- 기존 대출의 개별 월초 잔액, BULLET 만기 월 순현금 목표 등 근거가 없는 값은 null이다. 현재 값을 과거 자료로 복제하지 않는다.
