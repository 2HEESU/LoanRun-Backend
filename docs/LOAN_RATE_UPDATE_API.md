# 대출 금리 변경 등록 (#19)

`POST /api/loans/{loan_id}/rate-history/`는 익명 세션 소유자의 변동금리 대출에 `effective_date`, `annual_rate`를 받아 201 `LOAN_RATE_UPDATE_SUCCESS`를 반환한다. 금리는 0 이상 30 미만, 소수 2자리까지이며 적용일은 최신 잔액 스냅샷·금리 효력일 이후부터 오늘까지다. 중복/역전은 409 `RATE_HISTORY_CONFLICT`, 고정금리는 400 `RATE_CHANGE_NOT_ALLOWED`, 타인/삭제/없는 대출은 404다.

사용자/대출 잠금 아래 이력 추가, 현재 금리·갱신일·원리금 앵커, 미확정 미래 저장 회차, 예산 재계산, revision을 한 트랜잭션으로 처리한다. 원금균등 고정 원금은 유지하며 원리금균등 앵커는 남은 분할 회차와 새 금리로 계산한다. 은행 입력 다음 납부액은 해당 회차에만 유지한다. 과거 회차, 실제 납부, 잔액 스냅샷, 원래 계획/목표는 변경하지 않는다. 재계산 계획은 현재 금리의 공통 엔진 결과다.

부분 납부·미충족 과거 회차·복수 미래 확정 기준 등 현재 계산 원천을 안전하게 확정할 수 없는 경우, 확정 미납 표시/비용/납부 배분이 있는 대상 회차는 409로 거절한다. 충돌 메시지는 상세 API의 `RATE_HISTORY_CONFLICT` 메시지를 유지한다. 없는 미래 회차를 생성하지 않는다.

실제 `BudgetRecalculationPort`, 예산 조회 및 V4 계획 원천이 필요하다. 공급 부재/실패 시 503이며 이미 수행한 쓰기와 revision도 롤백된다. V4 SQL은 제안/격리 테스트용 상태를 유지하며 런타임 Flyway에 추가하지 않는다. 테스트의 공급 대역은 테스트 문맥에만 있다. 마이그레이션·환경변수·의존성 변경 없음.
